# 📸 Nathalie Mota 

## Description du Projet
Ce projet vise à créer un site web pour Nathalie Mota, une photographe d'événements. Le site a été conçu comme une galerie dynamique permettant à Nathalie de présenter ses photos, de les organiser par catégorie et format, et de les rendre facilement accessibles à ses clients.

L'objectif était de fournir une interface intuitive, à la fois pour les visiteurs qui souhaitent explorer les photos et pour Nathalie qui peut gérer facilement ses contenus depuis l'administration WordPress.

## Fonctionnalités Clés

1. **Hero Banner**
   - Image de couverture avec un titre central "Photographe Event".
   - Chargement d’une image aléatoire pour chaque visite.

2. **Galerie Dynamique**
   - Affichage des photos sous forme de grille.
   - Filtres par catégories (Mariage, Réception, etc.) et formats (Paysage, Portrait).
   - Tri par date (plus récentes, plus anciennes).
   - Pagination infinie avec chargement Ajax pour une navigation fluide.

3. **Lightbox**
   - Affichage plein écran d’une photo avec un overlay sombre.
   - Navigation entre les photos directement dans la lightbox.
   - Affichage des informations sur la photo (référence et catégorie).

4. **Modal de Contact**
   - Formulaire de contact accessible depuis chaque photo.
   - Champ pré-rempli avec la référence de la photo sélectionnée.

5. **Responsive Design**
   - Optimisation pour desktop, tablette et mobile.
